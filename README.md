# Set1 Analytics — Google Tag Manager Template

Automatically capture user interactions, traffic attribution, and GA4
ecommerce events with [Set1](https://set1.io).

## Setup

1. In your GTM container, go to **Tags > New > Tag Configuration**.
2. Search the Community Template Gallery for **Set1 Analytics**.
3. Enter your **Site Key** (found in your Set1 dashboard under Settings > Property).
4. Set the trigger to **All Pages**.
5. Publish your container.

## What gets tracked

- **Interactions** — clicks, mouse movement, scroll, keyboard, touch
- **Attribution** — traffic source, referrer, device, navigation timing
- **GA4 ecommerce events** — purchase, add_to_cart, view_item, and more
  (automatically captured from the dataLayer)

If you also use the Set1 Shopify app, ecommerce events are automatically
deduplicated — the Shopify integration takes priority.
